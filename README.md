# 백년해방 맛집 지도

유튜브 채널 [백년해방](https://youtube.com/channel/UCSW_W-SE71e9OhZwPEkEDLA)에 소개된 481개 맛집을 지도에 표시한 모바일 친화적 single-file HTML.

## 데모
👉 https://spring7day.github.io/youtube-food-map/

## 기능
- Leaflet + OSM 타일 기반 인터랙티브 지도
- 마커 클러스터링
- 광역(구) 단위 필터 칩
- 식당명/지역 실시간 검색
- 현재 위치 기반 주변 맛집
- 마커 클릭 시 상세 정보 + 유튜브 영상 링크
- 홈 화면 앱(PWA) — 아이폰에 앱처럼 설치, 오프라인 동작

## 아이폰에 앱으로 추가하기

1. 사파리로 [데모 링크](https://spring7day.github.io/youtube-food-map/)를 연다
2. 공유 버튼(□↑) → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행하면 사파리 툴바 없는 전체화면으로 뜬다

앱스토어 등록이나 개발자 계정은 필요 없다.

### 오프라인 동작

서비스 워커(`sw.js`)가 앱 셸을 캐시하므로 네트워크가 없어도 실행된다.

| 기능 | 오프라인 |
|---|---|
| 식당 목록 · 검색 · 필터 · 상세 | ✅ (396건이 `index.html`에 인라인) |
| 지도 타일 | 한 번 본 지역만 (최대 900장 캐시, FIFO 축출) |
| 내 위치 | ✅ (GPS는 네트워크 불필요) |
| 유튜브 영상 링크 | ❌ |

홈 화면에 추가된 웹앱은 사파리의 "7일 미사용 시 스토리지 삭제" 정책에서 제외되므로 캐시가 유지된다.

### 캐시 갱신

`index.html`은 네트워크 우선(3.5초 타임아웃 후 캐시 폴백)이라 온라인이면 실행할 때마다 최신 데이터를 받는다.
Leaflet 버전을 올리는 등 정적 자산을 바꿨을 때는 `sw.js`의 `VERSION`을 올려야 이전 캐시가 정리된다.

### 아이콘 재생성

`icons/`의 PNG는 `make_icons.py`가 zlib만으로 직접 인코딩한다 (Pillow 등 외부 의존성 없음).
색상이나 모양을 바꾸려면 스크립트를 수정하고 다시 실행한다.

```bash
python3 make_icons.py        # → icons/*.png
```
